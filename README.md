# Alicorp · presentación empresarial

Presentación web interactiva sobre Alicorp, sus marcas, líneas de negocio, resultados y sostenibilidad.

## Desarrollo local

1. Instala Node.js 20 o superior.
2. Ejecuta `npm install`.
3. Ejecuta `npm run dev` y abre la dirección que muestra Vite.

## Producción

- Comando de build: `npm run build`
- Directorio de salida: `dist`
- Despliegue estático compatible con Vercel.

En la presentación, usa las flechas ↑ y ↓, Page Up / Page Down, Inicio / Fin o los controles en pantalla para cambiar de diapositiva.

Los datos corporativos citados corresponden al Reporte Integrado 2025 y las demás fuentes se enlazan desde la diapositiva de referencias.
